# Bloom Valley Nursery

## Project Overview

Bloom Valley Nursery is a multi-page website created as part of a Web Development Touchstone project. The website promotes a local plant nursery by providing information about products, services, community involvement, and customer engagement opportunities.

## Website Features

* Multi-page website structure
* Homepage introducing the nursery
* Gallery page featuring nursery products
* About Us and Contact page
* Community page highlighting local involvement and events
* Newsletter subscription feature
* Contact and custom order request form
* Local storage implementation
* Responsive and accessible design

## Technologies Used

* HTML5
* CSS3
* JavaScript
* localStorage

## Website Pages

### Home Page

Introduces Bloom Valley Nursery, featured products, seasonal promotions, shopping perks, and product categories.

### Gallery Page

Showcases nursery products and gardening supplies through an organized image gallery.

### About Us / Contact Page

Provides business information, operating hours, and a contact form for customer inquiries and custom orders.

### Community Page

Highlights customer testimonials, community involvement, workshops, and local gardening events.

## Design Choices

This project uses:

* Color Palette 2
* Typography Option 2
* Matching Palette 2 Logo
* Accessible color and typography selections

The design focuses on creating a welcoming, natural, and community-oriented experience that reflects the values of a local nursery.
